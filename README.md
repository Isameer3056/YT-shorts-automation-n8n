# Health Fact — Fully Automated Daily Nutrition Shorts

An end-to-end n8n pipeline that researches a nutrition topic, writes a script, fact-checks it, generates a voiceover, sources stock visuals, assembles a vertical video with burned-in captions, and (optionally) uploads it to YouTube — once a day, hands-off, running entirely on free-tier infrastructure.

No manual editing, no paid APIs, no SaaS video renderer. Just n8n, a few free-tier accounts, and a self-hosted Oracle Cloud VM.

---

## What this actually does

Every day, on a schedule:
1. Pulls the next unused topic from a Google Sheet (e.g. *"Vitamin C sources beyond oranges"*)
2. Sends it to an LLM (Groq/Llama 3.3 70B) to research 3-4 facts and write a 45-60 second script
3. Runs those facts through a **second, independent** LLM call that rates each claim's confidence (HIGH/MEDIUM/LOW) — anything less than HIGH branches to an email alert instead of auto-publishing
4. Generates a voiceover via a self-hosted, offline TTS engine (Piper)
5. Fetches relevant stock images per topic (Pexels, with Pixabay as fallback)
6. Assembles everything into a 1080×1920 vertical video with a slow Ken Burns zoom per image and burned-in captions (ffmpeg)
7. Uploads to YouTube with a title, description, tags, and hashtags generated by the same script-writing step
8. Marks the topic as used, so tomorrow's run picks a fresh one

## Tech stack

| Component | Tool | Why |
|---|---|---|
| Orchestration | [n8n](https://n8n.io) (self-hosted, Docker) | Visual workflow builder; only way to get unlimited free video rendering is self-hosting |
| Hosting | Oracle Cloud **Always Free** tier | Genuinely free forever (2 OCPU / 12 GB Ampere A1), no card charges possible without an explicit account upgrade |
| Reverse proxy / HTTPS | [Caddy](https://caddyserver.com) + [DuckDNS](https://www.duckdns.org) | Free subdomain + automatic Let's Encrypt certs — required for Google OAuth callbacks |
| Topic queue | Google Sheets | Simple, human-editable backlog |
| Script writing + fact-check | [Groq API](https://console.groq.com) (Llama 3.3 70B) | Genuinely free tier, no card required, generous daily rate limit |
| Text-to-speech | [Piper](https://github.com/OHF-Voice/piper1-gpl) via `rhasspy/wyoming-piper`, bridged over HTTP | Fully offline, no API key, no card, unlimited use |
| Stock visuals | Pexels API + Pixabay API | Free, no card, good food/nutrition coverage |
| Video assembly | ffmpeg, bridged over HTTP (Execute Command node is disabled by default in n8n 2.0+) | Zero-cost, unlimited renders |
| Upload | YouTube Data API v3 (native n8n node) | Already-available quota comfortably covers 1 upload/day |

## Setup

### 1. Provision the VM
Any Ampere A1 (arm64) instance with 2 OCPU / 12 GB RAM works. Oracle's Always Free tier is the reference target; any equivalent arm64 VM with Docker works too.

### 2. Point a free subdomain at it
[DuckDNS](https://www.duckdns.org) → create a subdomain → point it at the VM's public IP.

### 3. Clone this repo onto the VM and configure
```bash
git clone <this-repo-url>
cd health-fact
```
Edit `docker-compose.yml` and `Caddyfile`, replacing the placeholder domain with your actual DuckDNS subdomain.

### 4. Bring up the stack
```bash
docker compose up -d --build
```
This builds n8n (with a static ffmpeg binary baked in), and starts Caddy (automatic HTTPS), Piper + its bridge, and the ffmpeg bridge — all networked together.

### 5. Open n8n and build the workflow
Visit `https://<your-subdomain>`, create your owner account, and either import `docs/workflow-export.json` or build the nodes following the walkthrough below.

### 6. Credentials you'll need
- Google Sheets OAuth2 (topic queue)
- Groq API key (script + fact-check)
- Pexels API key, Pixabay API key (visuals)
- Gmail OAuth2 (review alerts)
- YouTube Data API v3 OAuth2 (upload)

None of these require a credit card except the Google Cloud project itself (needed to unlock real API quota — the usage stays $0 at this scale).

## Workflow walkthrough

| Node | Purpose |
|---|---|
| Schedule Trigger | Fires once daily |
| Get Row(s) in Sheet | Pulls one unused topic (`used = false`), limited to 1 |
| HTTP Request (Groq) | Researches facts + writes script, returns structured JSON |
| Code (Parse Script) | Parses the JSON string into individual fields |
| HTTP Request (fact-check) | A **second, independent** Groq call rates each fact's confidence |
| Code (parse fact-check) | Merges fact-check results back with script data, computes a `needsReview` flag |
| IF | Branches on `needsReview` |
| → Gmail | (true branch) Emails flagged claims + suggested corrections; workflow stops here |
| → HTTP Request (Piper bridge) | (false branch) Generates the voiceover |
| Edit Fields + Split Out | Splits the 4-5 image search terms into individual items |
| HTTP Request (Pexels) → IF → HTTP Request (Pixabay, fallback) → Merge | Fetches one relevant image per search term |
| HTTP Request (download) + Write to Disk | Saves images as real files |
| Code (build SRT) + Convert to File + Write to Disk | Builds burned-in caption timing |
| HTTP Request (ffmpeg bridge) | Assembles the final vertical video |
| YouTube (upload) | Publishes the Short with generated title/description/tags/hashtags |
| Update row in Sheet | Marks the topic as used |

## Lessons learned (the hard way)

This pipeline looks simple in the diagram above. Getting there involved a long list of very specific, very real problems — documenting them here in case they save someone else time:

- **Oracle's Always Free Ampere capacity is genuinely scarce** in some regions/Availability Domains. A retry script that automates the "click Create, see Out of Host Capacity, wait, retry" loop is the practical fix — just respect Oracle's launch API rate limit (a 5-minute interval avoids tripping it).
- **n8n's official Docker image (v2.x+) is distroless** — no `apt`, no `apk`, not even basic shell utilities. Adding ffmpeg means copying in a **statically-linked binary** via a multi-stage `COPY --from=`, not installing a package.
- **A public subnet needs an explicit route to an Internet Gateway** — the Security List alone isn't enough. If SSH/HTTPS times out despite correct firewall rules, check the VCN's route table before anything else.
- **Google's Gemini API "Free Tier" (no billing linked) is capped at zero quota** for current models — the real, usable free allowance requires linking a billing account (still $0 unless you exceed it). **Groq** is a genuinely card-free alternative with a real, usable free tier.
- **The Wyoming protocol** (used by Piper for TTS) isn't HTTP — bridging it to a workflow tool that only speaks HTTP means writing a small wrapper using the official client library, not hand-rolling the wire protocol from memory.
- **n8n's Execute Command node is disabled by default since v2.0** for security reasons. Rather than fighting the re-enable flags (which have known bugs), a tiny sidecar container exposing the needed shell command (ffmpeg, in this case) over a plain HTTP endpoint is more reliable.
- **n8n restricts filesystem node access by default** (`N8N_RESTRICT_FILE_ACCESS_TO`) — any shared data directory needs to be explicitly allow-listed via environment variable, even if the Docker volume mount itself is correct.
- **`$('NodeName')` references are exact-string lookups** — rename nodes to something descriptive early, since n8n auto-updates references on rename, which is much safer than guessing a name mid-build.

## Cost

At one video/day, every component in this stack runs entirely within free tiers. The only real "cost" is the setup time and the VM itself, which is free under Oracle's Always Free program.

## Disclaimer

This project uses AI-generated research and scripts. The fact-checking step reduces but does not eliminate the risk of inaccurate claims — review flagged content before publishing, and treat this as a production accelerator, not a replacement for editorial judgment on health/nutrition content.
